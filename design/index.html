Kurisa 阅读器 · Material 3 / M3E 界面

Kurisa 是本地优先的阅读器 + 可扩展内容接入框架：应用本体不预置任何内容（C1）， 源的装载、签名与白名单由用户掌控（C2），断网时书架与已下载必须可用（C4）。 因此界面以「用户自己的书架」为主入口，源管理页承担安全叙事，阅读器是唯一的全屏沉浸页。

以参考应用（Komikku）的页面结构与交互为骨架：5 个底部目的地、自适应封面网格、模糊信息头、 章节列表、沉浸式阅读器、设置列表；组件替换为 Material 3 Expressive 现行件 （ShortNavigationBar、ButtonGroup、FloatingToolbar、WavyProgress、Slider 4dp 手柄、 强调字阶）。配色沿用参考应用的 Material You 蓝（primary #0058CA / #B0C6FF）， tertiary 绿只用于进度与已下载。

设计基准

页面结构、信息密度、导航层级来自参考应用；M3E 只作用在组件与视觉语言上，不改变用户已有的操作路径。

03

组件

只用 M3/M3E 现行组件：flexible NavigationBar（比 80dp 基线更矮，选中标签 secondary）、 TopAppBar 64dp（滚动后 surface-container）、PrimaryTabRow 48dp（3px 内容宽指示器）、 FilterChip（8dp → 全圆，label-large 14）、ButtonGroup（标准组间隙 / 连接组 2dp 仅用于选择）、 FAB 56/80/96（primary-container，elevation 3）、ModalBottomSheet（顶部 28dp，scrim 32%）、 LinearWavyProgressIndicator、Slider。按钮 XS–XL 五档，按压向方形 morph； 动效用 emphasized 曲线 + duration 刻度（进入 400ms decelerate / 退出 200ms accelerate）。

05

响应式

严格沿用 M3 窗口尺寸类（5 档）与 3 种规范布局：书架是 Feed（列数随宽度涨，边距/沟槽按档切换）， 作品详情是 List-detail（compact 单窗格跳转，medium 起列表与详情并排）， 宽屏下的「网格 + 详情预览」是 Supporting pane（主区 2/3 + 副区 1/3）。 导航只换组件不换目的地：ShortNavigationBar → NavigationRail → WideNavigationRail。 下面是 live demo —— 拖滑杆，布局按 container queries 真实重排，不是缩放截图。
